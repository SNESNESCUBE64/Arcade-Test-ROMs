# SNESNESCUBE64's Arcade Test ROMs

This repo contains several test ROMs for different arcade games. The purpose of these is to help troubleshoot and diagnose hardware. Like with all test ROMs, these are not fool proof. You still have to know the hardware and know what to do with the results. The goal is to ultimately figure out some unknowns during the troubleshooting process. 

## List of Test ROMs
List of statuses:
- Not Started: No work has been done yet
- In Progress: Work has started but is still being developed
- Completed:   Work is done, but can still be updated in the future.
- Ready:       Work is done, tools are ready to be used.
